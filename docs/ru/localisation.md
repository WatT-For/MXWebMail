# Перевод / языки

*Переведено с французского - французская версия является исходной.*

## 1. Работа

Локализация опирается на PHP-словари `ключ => текст`:

- ядро: `app/src/MXWebMail/Locale/<lang>.php`;
- плагины: `app/plugins/<name>/langs/<lang>.php` (ключи с префиксом
  `plugin.<name>.`);
- темы: `app/templates/<name>/langs/<lang>.php` (ключи с префиксом
  `theme.<name>.`).

Переводчик объединяет эти источники (сначала ядро, затем плагины, затем
темы - последние выигрывают при коллизии), с английским (`en`) как **базовым
языком** (fallback), за которым следует активный язык. `t('ключ', $params)`
выполняет интерполяцию `{param}`; неизвестный ключ возвращается как есть.

## 2. Установленные языки

Доступны 10 языков: **de, en, es, fr, it, nl, pl, pt, ru, tr**. Базовый
язык (fallback) - **английский**: `app/src/MXWebMail/Locale/en.php` должен
оставаться исчерпывающим.

## 3. Выбор языка

`language` в `config.php` (или админ > *Общие*):

- `auto` (по умолчанию): заголовок `Accept-Language` браузера;
- иначе код установленного языка (`fr`, `en`…).

Финальный fallback: `en`. Фронтенд получает полный словарь в
`window.MXWM.i18n` (используется через `i18n.js`).

## 4. Добавление языка

1. Создайте `app/src/MXWebMail/Locale/<code>.php`:
   `return ['ключ' => 'текст', …]`.
2. (Рекомендуется) добавьте словари плагинов и тем:
   `app/plugins/*/langs/<code>.php`, `app/templates/*/langs/<code>.php`.
3. Язык автоматически появляется в селекторе админа (список = файлы в
   `Locale/`).

Никакого центрального реестра: достаточно наличия файла.

## 5. Сторона PHP и JS

- PHP: `$this->t('ключ')` в контроллерах/плагинах; `t('ключ')` в шаблонах.
- JS: `ctx.t('ключ')` в `mount(element, ctx)` плагинов; `t('ключ')` через
  `i18n.js`.

`label`/`help`/`description` манифестов (`plugin.json`, `theme.json`) и
схем (`config.schema.json`) принимают ключи перевода (pass-through, если
ключ неизвестен).

## 6. Паритет словарей

Английский - базовый язык: каждый новый ключ сначала добавляется в
`en.php`, и каждый словарь должен оставаться на уровне `en`.

## 7. Переведённая документация

У каждого языка веб-почты свой каталог `docs/<lang>/` (`fr`, `de`, `en`, `es`,
`it`, `nl`, `pl`, `pt`, `ru`, `tr`) с теми же именами файлов. Французский в
`docs/fr/` - эталонная версия: любое изменение канонического документа должно
быть перенесено в переводы, и каждая новая статья должна создаваться в каждом
языке.
